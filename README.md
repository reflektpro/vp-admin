# Админка ГУ ВП

Отдельная страница для баллов, отработок и всех документов с номером из базы: приказы (ВГ, ПР), рапорты на взыскание (ВП), на повышение (ПВ) и еженедельные отчёты (ОТ). Во вкладке «Документы» любую запись можно поправить или удалить, номер меняется только если вписать новый, следующий номер ставится для каждого вида. Пароль в репозиторий не кладётся.

Пароль админки меняется прямо здесь: «Сменить пароль» (новый пароль дважды). Сразу после первого входа один раз показывается код сброса — его надо записать, больше он не покажется. Если пароль утёк или забыт, на странице входа «Забыл пароль»: код сброса и новый пароль. Код и пароли в репозиторий не кладутся.
